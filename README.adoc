= UniConfig Config Panel

Schema-driven Control Panel for config files that never grew a settings UI.

link:https://docs.devcentr.org/uniconfig/latest/[Explore the docs »]
endif::[]

== About The Project

Open INI, YAML, TOML, SDLang, JSON, or `.tfvars`. The panel shows labels, enums, and **fields that are legal but absent**. Profiles in SDLang map filename globs onto JSON Schema. Opened files register into a tree stored as `registry.sdl`.

The parser/schema engine is a separate repo: link:https://github.com/dev-centr/uniconfig-core[uniconfig-core] — DevCentr can depend on that without dlangui.

== Getting Started

=== Prerequisites

LDC or DMD, DUB. Clone `uniconfig-core` as a sibling (`../uniconfig-core`).

=== Build

[source,powershell]
----
dub build --config=application
.\uniconfig.exe --help
----
