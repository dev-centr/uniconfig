== Vocabulary discovery (lazy)

When a file opens, the engine:

. Reads `%LOCALAPPDATA%\UniConfig\catalog-index.sdl` (prunes missing paths)
. Loads matching registered `catalog.sdl` + schema on demand
. Falls back to bundled profiles (Git, DUB, tfvars, …)
. Tries sidecar / `$schema` pointers
. Infers types from instance keys

No merged mega-catalog on disk. See xref:howto-ship-vocabulary.adoc[Ship vocabulary].

== Connectome-fs alignment (forward)

Intra-file `/schema` and `/data` forks (see link:https://connectome-fs.github.io/connectome-fs/docs/explanation/intra-file-resource-forks.html[Intra-file resource forks]) will slot into the resolver **before** external sidecars — same schema − instance model, co-located streams.

== Optional Vello

dlangui `vello-windows` is experimental GPU clear behind GDI widgets. Default builds use dlangui `default`.

== Formula (sanity)

stem:[n_{\text{unset}} = \lvert S \setminus I \rvert]

where stem:[S] is the schema property set and stem:[I] is the instance key set.
