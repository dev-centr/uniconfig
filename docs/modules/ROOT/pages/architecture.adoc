== Repositories

[cols="1,2"]
|===
| `uniconfig-core` | Engine: codecs, schema merge, `form_model`, catalog index, profile resolver, registry.
| `configui-binders` | Toolkit binders (dui, dlangui, Qt, GTK, Avalonia, web).
| `uniconfig` | ConfigUI app shell + `fallback-catalog/` for Git/Terraform/DUB when those tools never ship vocabulary.
|===

== Layers

[source,text]
----
ConfigUI (app) ── registry tree, format banner, file I/O
    └── configui-dlangui (default today; configui-dui is the target desktop binder)
            └── uniconfig.core.form_model (FormRow / flattenFormRows — in engine)
                    └── UniConfig engine (codecs, catalog index, sidecars)
                            └── fallback-catalog/ (shipped with app only)
----

== Vocabulary discovery

When a file opens:

. Registered app catalogs (`catalog-index.sdl`)
. Bundled `fallback-catalog/` (third-party tools only)
. Sidecar `*.schema.json` / `$schema`
. On-the-fly inference

No intra-file fork reader in UniConfig until connectome-fs exposes fork I/O.
