= UniConfig Config Panel
:description: Schema-driven Control Panel for config files that never grew their own settings UI.
:navtitle: Introduction

**UniConfig Config Panel** is a desktop app (D + dlangui) that opens ordinary config files — INI, YAML, TOML, SDLang, JSON, `tfvars` — and shows the same settings metaphors every time: labels, enums, toggles, descriptions, and **fields the author never wrote**.

The reusable engine lives in a second package, link:https://github.com/dev-centr/uniconfig-core[uniconfig-core], so DevCentr can depend on the tree without pulling a GUI.
